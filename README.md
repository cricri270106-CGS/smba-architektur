# meyer bauleitung+architektur gmbh – Gestaltungsvorschlag

Neuer Webauftritt als Vorschlag für die meyer bauleitung+architektur gmbh, Fräschels.

Statische Seite (HTML/CSS/JS, keine Build-Schritte), gehostet über GitHub Pages.

- `styles.css` – Gestaltung (Hell-/Dunkelmodus)
- `app.js` – Projektfilter, Projektansicht, Team, Animationen
- `projects.js` – 32 Projekte von smba.ch
